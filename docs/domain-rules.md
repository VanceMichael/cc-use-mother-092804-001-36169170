# 领域边界

保存大熊猫跨境旅居的运输、检疫、照护记录与责任交接。

现有领域资料围绕以下边界组织：

- 动物身份与旅居协议
- 运输与检疫事件
- 照护计划与交接
- 物资与健康观察
- 争议时点回放

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 服务落地边界

`src/panda_care/` 在此边界内提供只追加照护档案：

- 档案阶段限定为出发前评估、装运封存、航程、入园适应四阶段，门禁只能向前；
- 记录类型限定为照护计划、评估与兽医结论、封存、航程事件、喂养、用药、观察、
  物资批次、范围化检疫/延误/替代/隔离、责任交接、报告与复核；
- 记录只能追加，兽医结论只能以新结论修正，任何删除或改写不在服务能力内；
- 信息按 CN / US / BOTH 三个可见域过滤，争议证据包只包含链上已入链事件。

# 跨境旅居动物照护与责任交接

保存大熊猫跨境旅居的运输、检疫、照护记录与责任交接。

## 参与方与事实

主要参与方包括动物园运营人员、中方饲养员、美方兽医、运输承运方、项目管理机构、指定复核兽医。领域资料记录以下已经确认的事实：

- 大熊猫平平和福双抵达美国亚特兰大动物园
- 双方安排旅居期限为十年
- 跨境运输需要持续的照护和检疫衔接
- 照护档案覆盖出发前评估、装运封存、航程事件与入园适应期
- 每条喂养、用药、体重观察和行为异常都记录发生时间与责任人
- 报告以内容哈希去重，内容矛盾时转指定兽医复核
- 中美双方信息范围不同，争议时按入链时点回放照护计划、物资去向与交接依据

## 业务约束

- 跨境交接须双方共同确认
- 检疫时效未满足不得进入航程或入园阶段
- 单只隔离只影响该动物的喂养与交接
- 照护记录不可覆盖，兽医结论只能以新结论修正
- 最小信息披露，按中/美方侧别过滤
- 范围化事件必须登记恢复条件且不得重复解除
- 重复报告返回原处理结果，不产生新记录

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例（当前为版本 2），`src/panda_context.py` 负责读取和校验这些资料。

## 照护服务

`src/panda_care/` 提供可运行的领域服务，规则见 [docs/service-design.md](docs/service-design.md)：

- **连续档案**：出发前评估 → 装运封存 → 航程事件 → 入园适应，阶段门禁只能向前推进；
- **只追加哈希链**：每条记录带发生时间与责任人，换班只能追加；SHA-256 哈希链可校验、防篡改；
- **兽医结论锁定**：已确认结论不可改写，修正只能新增结论并取代旧结论；
- **范围化事件**：检疫、航线延误、饲料替代、单只隔离只挂接相关动物/计划条目/批次，必须登记恢复条件；
- **幂等上传**：重复上传同一报告返回原结果；内容矛盾转指定兽医复核，冲突结论复核期间挂起；
- **侧别视图与争议回放**：中美双方可见范围不同；任一时点可还原照护计划、物资去向与交接依据。

事件信封契约见 `contracts/care-events.schema.json`。

## 开发命令

运行测试：


编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。

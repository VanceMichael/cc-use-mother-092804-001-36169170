# 跨境旅居动物照护与责任交接

保存大熊猫跨境旅居的运输、检疫、照护记录与责任交接。

## 参与方与事实

主要参与方包括动物园运营人员、中方饲养员、美方兽医、运输承运方、项目管理机构。领域资料记录以下已经确认的事实：

- 大熊猫平平和福双抵达美国亚特兰大动物园
- 双方安排旅居期限为十年
- 跨境运输需要持续的照护和检疫衔接

## 业务约束

- 跨境交接
- 检疫时效
- 单只隔离
- 照护记录不可覆盖
- 最小信息披露

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/panda_context.py` 负责读取和校验这些资料。

## 照护服务核心模型

`src/transit_care.py` 在领域资料之上实现跨境照护服务的核心规则：

- **连续档案**：出发前评估 → 装运封存 → 航程 → 入境检疫 → 入园适应 → 十年旅居；每条喂养、用药、体重、行为记录都带发生时间（必含时区）与责任人，并以哈希链串联，只能追加、不能改写。
- **兽医结论锁定**：确认结论只能由兽医以追加"纠正"取代，原结论保留；换班人员无法修改。
- **作用域偶发事件**：检疫扣留、航线延误、饲料替代、单只隔离只影响指定环节（和指定动物），必须写明恢复条件，关闭同样以追加记录完成。
- **报告幂等受理**：同一内容哈希重复上传返回原处理结果；与有效兽医结论矛盾时进入指定兽医复核队列，裁决须写依据。
- **饲料批次与交接**：批次入库唯一、喂养扣减结余；交接固定照护计划版本、批次清单与记录区间。
- **最小披露与时点回放**：中美双方视图不同（共享 + 本方），共同管理机构可按任意时点还原照护计划、物资去向、事件状态、有效结论与交接依据。

规则细节见 `docs/domain-rules.md`，行为示例见 `tests/test_transit_care.py`。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
